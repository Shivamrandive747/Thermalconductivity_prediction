# Almost all of these will be Introduction citations -- background on half Heuslers,
# thermoelectrics, the Callaway model, the Kim-Snyder Lorenz parameterisation, CatBoost,
# and the structure databases. That is exactly where fabricated citations would hide, so the
# rule is stricter here, not looser:
#
#   1. FIND the paper by a real search (OpenAlex or Crossref). Never from memory.
#   2. READ the abstract. A title can match a claim the paper does not make.
#   3. RECORD the supporting sentence in claims_ledger.csv BEFORE adding the DOI here.
#   4. Add the bare DOI below, one per line, then re-run build_bibliography.py.
